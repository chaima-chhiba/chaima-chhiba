##  Featured Projects

###  [Secure CI/CD Pipeline](https://github.com/chaima-chhiba/secure-cicd-demo)

An end-to-end DevSecOps pipeline integrating security checks into the software delivery lifecycle.

- **Security:** Gitleaks, Semgrep, OWASP Dependency-Check, Trivy and Syft for SBOM generation.
- **Infrastructure:** Terraform, Kubernetes and hardened Docker images.
- **Observability:** Prometheus and Grafana.

### [OWASP Juice Shop Penetration Test](https://github.com/chaima-chhiba/owasp-juiceshop-pentest)

A hands-on web application security assessment documenting 23 identified vulnerabilities mapped to OWASP Top 10 (2021).

- Identified and documented critical findings, including SQL injection and privilege escalation.
- **Tools:** Burp Suite, OWASP ZAP, ExifTool and ffuf.
- Detailed proof-of-concept documentation and remediation recommendations.
