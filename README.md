## 🔐 Featured Projects

### 🔒 [Secure CI/CD Pipeline](https://github.com/chaima-chhiba/secure-cicd-demo)
A production-grade DevSecOps pipeline that automatically scans every push with 5 security tools before deployment.
- **Security gates:** Gitleaks (secrets) · Semgrep (SAST) · OWASP Dependency-Check (SCA) · Trivy (container scanning) · Syft (SBOM)
- **Infrastructure:** Kubernetes (Minikube) managed via Terraform, hardened Docker image
- **Monitoring:** Prometheus + Grafana live cluster dashboards
- Only verified, vulnerability-free images are pushed to Docker Hub

### 🛡️ [OWASP Juice Shop Penetration Test](https://github.com/chaima-chhiba/owasp-juiceshop-pentest)
A full penetration test identifying and exploiting **23 vulnerabilities** mapped to the OWASP Top 10 (2021).
- 7 Critical findings including SQL Injection, JWT/role-based privilege escalation, and a Chatbot VM Escape (RCE)
- Tools: Burp Suite, OWASP ZAP, ExifTool, ffuf, z85-cli
- Full PoC documentation with exploitation steps and remediation for each finding
